# Comandos

Usuário: `/start`, `/saldo`, `/products`, `/check TRANSACTION_ID`

Admin: `/addproduct CATEGORIA|NOME|DESCRIÇÃO|PREÇO`, `/addstock IDENTIFICADOR_12_16|CODIGO_5|CODIGO_3_4|NOME_FICTICIO|NUMERO_10|VALOR`, `/stock`, `/giftcreate VALOR`.

Botões: Produtos, Saldo, Depositar PIX, Resgatar Gift.

O estoque é exclusivamente para produtos digitais fictícios. Não inserir dados de cartões, CVV, credenciais ou documentos reais.
